## 📌 Overview
Website ini adalah portofolio pribadi sederhana yang dibuat menggunakan HTML dan CSS.  
Tujuan utama website ini adalah sebagai tempat belajar coding, sekaligus menampilkan profil, pengalaman, dan project yang sedang dikerjakan.

Website ini memiliki tampilan clean dan minimal dengan nuansa warna warm (coklat & cream), serta struktur yang mudah dipahami.

---

## ✨ Features Implemented
- Navigation bar dengan smooth scroll
- Hero section (intro + foto)
- About Me section (profil & tools)
- Projects section dengan grid layout
- Contact section dengan tombol menuju halaman form (`form.html`)
- Responsive grid menggunakan CSS Grid (`auto-fit`)
- Button styling untuk navigasi
- Smooth scrolling (`scroll-behavior: smooth`)
- Image styling (border radius & responsive image)
- Footer sederhana

---

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox & Grid)
- Unsplash (image assets)
- Giphy (GIF animation)
